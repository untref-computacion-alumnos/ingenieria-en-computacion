# Backlog — Reviews of subjects and teachers (US-5xx)

Depends on verified students (US-202) and the moderation base from Community (US-409..412).

| ID | Story |
| --- | --- |
| US-501 | As a **verified student**, I want to rate a subject on structured scales (difficulty, workload, clarity, usefulness), so that others get comparable data. |
| US-502 | As a **verified student**, I want to review a teacher on structured scales, so that feedback is consistent and respectful. |
| US-503 | As a **verified student**, I want to choose to post anonymously (identity hidden but verified) or publicly, so that I decide my exposure. |
| US-504 | As a **student**, I want to write an optional comment with my rating, so that I can add context. |
| US-505 | As a **student**, I want to see aggregated ratings per subject and teacher with a minimum number of reviews, so that outliers don't mislead. |
| US-506 | As a **moderator**, I want comments held in a queue until approved (or auto-approved if clean), so that disrespectful content is filtered. |
| US-507 | As a **moderator**, I want detection of insults and evasion techniques, and a log of blocked attempts, so that the filter improves. |
| US-508 | As a **teacher**, I want to see feedback about my subjects and reply once, so that the conversation is fair. |
| US-509 | As a **student**, I want only one review per subject and teacher per term, so that ratings cannot be stuffed. |
| US-510 | As a **team**, we want a clear community policy and appeal path, so that moderation is transparent. |
