# Backlog — Community (US-4xx)

A suggestions board with votes, combined with threads, categories, replies and per-subject discussion.

| ID | Story |
| --- | --- |
| US-401 | As a **student**, I want to post an idea in a suggestions board, so that I can propose improvements to the app. |
| US-402 | As a **student**, I want to vote ideas up, so that the team knows what matters (acts_as_votable). |
| US-403 | As a **team member**, I want to set an idea's status (under review, planned, done, declined), so that people see progress. |
| US-404 | As a **student**, I want to reply to an idea and to other replies (threads), so that we can discuss. |
| US-405 | As a **student**, I want categories and tags for threads, so that topics are findable. |
| US-406 | As a **student**, I want a discussion space per subject, so that questions stay with their subject. |
| US-407 | As a **student**, I want to search threads and ideas (pg_search), so that I don't duplicate them. |
| US-408 | As a **student**, I want readable URLs (friendly_id), so that links are shareable. |
| US-409 | As a **student**, I want to report a post, so that abuse is handled. |
| US-410 | As a **moderator**, I want a moderation queue for reports and held posts, so that I can approve, hide or remove content. |
| US-411 | As a **moderator**, I want an editable banned-words list with text normalization (accents, repeats, leetspeak), so that insults and filter evasion are caught. |
| US-412 | As a **team**, we want rate limiting on posting (Rack::Attack), so that spam is limited. |
| US-413 | As a **student**, I want notifications when someone replies to me, so that I can follow conversations. |
