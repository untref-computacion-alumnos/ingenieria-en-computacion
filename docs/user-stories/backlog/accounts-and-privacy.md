# Backlog — Accounts and privacy (US-2xx)

| ID | Story |
| --- | --- |
| US-201 | As a **student**, I want to confirm my email address, so that the account is real. |
| US-202 | As a **student**, I want to verify my institutional email, so that I am recognized as a real student (needed for verified reviews). |
| US-203 | As a **student**, I want to export all my data, so that I control it. |
| US-204 | As a **student**, I want to delete my account and data, so that I can leave at any time. |
| US-205 | As a **student**, I want a profile page with my display name and privacy settings, so that I choose what is visible. |
| US-206 | As a **student**, I want to sign in with Google (OmniAuth), so that I don't need another password. |
| US-207 | As a **student**, I want to sign in with the faculty identity when available, so that login is unified. |
| US-208 | As a **team**, we want login attempts throttled (Rack::Attack) and account lockout, so that accounts are harder to attack. |
| US-209 | As an **admin**, I want to assign roles (teacher, moderator, admin) to users, so that permissions match responsibilities. |
| US-210 | As a **student**, I want to share my progress with a link (opt-in, revocable), so that I can show it to a tutor or friends. |
