# Backlog — Student tools (US-3xx)

| ID | Story |
| --- | --- |
| US-301 | As a **student**, I want to see my average grade, so that I know where I stand. |
| US-302 | As a **student**, I want a "what grade do I need" calculator, so that I can plan my exams. |
| US-303 | As a **student**, I want to record partial exam and assignment grades per subject, so that I follow my evaluations. |
| US-304 | As a **student**, I want a calendar of exam dates and enrollment windows for my subjects, so that I never miss one. |
| US-305 | As a **student**, I want to build my weekly schedule from the sections I take, so that I see my week. |
| US-306 | As a **student**, I want tasks and deadlines per subject, so that my pending work is in one place. |
| US-307 | As a **student**, I want to subscribe my calendar via iCal/Google Calendar, so that dates show up where I already look. |
| US-308 | As a **student**, I want email notifications for upcoming dates, so that I get reminders without opening the app. |
| US-309 | As a **student**, I want browser (web push) notifications, so that I get reminders on my phone. |
| US-310 | As a **student**, I want each subject's syllabus (contents, bibliography, approval mode), so that I know what to expect. |
| US-311 | As a **student**, I want to share and find past exams and notes per subject, so that I can study (with moderation and copyright rules). |
| US-312 | As a **student**, I want a simple "next steps" suggestion (subjects I can take now), so that planning a term is easy. |
| US-313 | As a **student**, I want to install the site as an app on my phone (PWA), so that it opens like an app. |
