# Backlog — Curriculum management (US-1xx)

Goal: keep plans accurate without developer work. Expand a story with the template when it nears the top.

| ID | Story |
| --- | --- |
| US-101 | As an **admin**, I want to sign in to an admin area (Administrate, role-gated), so that only authorized people manage data. |
| US-102 | As an **admin**, I want to create, edit and delete study plans, so that new plans are added without seeds. |
| US-103 | As an **admin**, I want to create, edit and delete subjects (year, term, hours/credits), so that the grid stays correct. |
| US-104 | As an **admin**, I want to manage course prerequisites with cycle validation, so that the grid is consistent. |
| US-105 | As an **admin**, I want to import a plan from a CSV file with a preview of errors, so that loading a plan is fast. |
| US-106 | As an **admin**, I want to define equivalences between subjects of two plans, so that students can change plans. |
| US-107 | As a **student**, I want to switch to another plan keeping my progress through equivalences, so that I don't lose my record. |
| US-108 | As a **student**, I want to see final-exam prerequisites ("approved X to sit the final"), so that I know what I can sit. |
| US-109 | As a **student**, I want count/credit prerequisites ("N subjects approved", "first cycle complete") evaluated, so that availability is right. |
| US-110 | As a **student**, I want electives grouped into pools with required credits, so that I can plan optional subjects. |
| US-111 | As a **student**, I want to see the intermediate degree requirements and my progress toward it. |
| US-112 | As a **student**, I want extra requirements (language, internship, thesis) tracked, so that I see everything needed to graduate. |
| US-113 | As a **student**, I want to propose a correction to a subject or prerequisite, so that data errors get fixed. |
| US-114 | As a **moderator**, I want to review, accept or reject proposed corrections with history (PaperTrail), so that changes are controlled. |
| US-115 | As an **admin**, I want to see the change history of a plan, so that I know who changed what. |
