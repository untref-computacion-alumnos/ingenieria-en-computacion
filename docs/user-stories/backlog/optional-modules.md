# Backlog — Optional modules (US-8xx)

All modules are off by default behind Flipper flags; each student can enable the ones they want in their profile.
The team can switch them on or off per environment, role or user.

| ID | Story |
| --- | --- |
| US-801 | As a **team**, we want a module framework (Flipper flag + user preference + nav entry), so that new modules plug in consistently. |
| US-802 | As a **student**, I want to enable or disable modules from my profile, so that I only see what I use. |
| US-803 | As a **student**, I want a Pomodoro timer, so that I can study in focused blocks. |
| US-804 | As a **student**, I want quick notes per subject, so that I jot things down where they belong. |
| US-805 | As a **student**, I want to track attendance per subject (classes held/missed, limit warning), so that I don't lose regularity. |
| US-806 | As a **student**, I want a contextual home (next exam, next class, what I can take) that only shows enabled modules, so that the first screen is useful and light. |
